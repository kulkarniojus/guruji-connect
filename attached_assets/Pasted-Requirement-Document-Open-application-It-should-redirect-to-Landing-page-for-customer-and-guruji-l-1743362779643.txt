On Booking
- Customer has to pay either full or partial payment of 50 percent prior booking
- On click of book it will redirect to payment portal where customer has to pay money and
once payment confirmed then it will redirect to map and request will go to pool for guruji&#39;s
- if incase of any failure, deducted money should go back to customer&#39;s acc and only on
payment confirmation we have to allow customer for booking
On Guruji side
- If Guruji is not accepting a request which is trigged within 10 km range then it should
increase range till 15 to 20 km for search after particular time
- This time and km range setting should be configured somewhere so owner or super
admin should be able to change it any point of time
- If Guruji has cancelled before 24 hrs then it should be free cancellation
- If Guruji has cancelled within 24 hrs then there should be penalty charged to Guruji.
- If Guruji Fail to pay penalty then app should give facility to block automatically and there
should be an additional option to block &amp; unblock it manually as well
- Guruji should get alert multiple times as a reminder for him for booked puja
- Address and phone no. should be sent to guruji 4 hrs before or the time should be
calculated as per booking time period of Puja
- for ex. if puja is booked 5 days before then guruji should be able to get address before
4 hr or 5 hrs
- this above time should be configurable somewhere in portal
- if puja is booked on urgent basis then address should be sent immediately or there
should be some algorithm to calculate this time period for such immediate cases ( need
ask startup how they can develop this algo on time and availability basis, there should be
some percent basis calculation)
